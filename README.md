# dev-standard-frontend

Skill de desarrollo frontend (Angular, signals, Tailwind, ECharts): estructura por features, reutilización obligatoria (Regla 0), orden de miembros de clase, responsive mobile-first y estilos centralizados. Se adapta a la versión real de cada proyecto.

## Instalación

Con la CLI de skills:

```
npx skills add https://github.com/<usuario>/<repo>
```

Manual (GitHub Copilot / Claude Code): copiar `skills/dev-standard-frontend/` a una de estas carpetas:

- Personal: `~/.copilot/skills/` o `~/.claude/skills/`
- Por proyecto: `.github/skills/` o `.claude/skills/`

Al activarse, la skill muestra el banner `▰▰▰ ✦ Mark frontend skill ✦ ▰▰▰` como primera línea de la respuesta.
